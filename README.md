# Rolling Stones — Exploratory Data Analysis

Projeto de **Exploratory Data Analysis (EDA)** desenvolvido a partir de uma base de dados relacionada à trajetória musical da banda The Rolling Stones.

## Objetivo

Explorar os dados e identificar padrões e tendências relacionados às características das músicas ao longo da trajetória da banda.

## Etapas da análise

* Importação dos dados
* Tratamento e organização da base
* Análise exploratória
* Criação de métricas
* Visualização dos dados
* Identificação de padrões
* Interpretação dos resultados

## Tecnologias

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook
* Excel
